# Memo — MVP сервиса для подготовки к экзаменам

Веб-сервис на React + TypeScript. Студент организует подготовку по предметам, загружает лекции для создания карточек с помощью ИИ, проверяет себя без подсказки и повторяет карточки через интервалы.

## Запуск

```bash
npm install
cp .env.example .env
# В .env укажите свой GEMINI_API_KEY из Google AI Studio
npm run dev
```

Открыть `http://localhost:3000`. В режиме разработки Vite запускает веб-интерфейс на порту 3000 и передаёт `/api` серверу на порту 3001. Оба процесса слушают только локальный интерфейс. Для production на обычном Node.js-хостинге: `npm run build && npm start`; сервер раздаёт интерфейс из `dist/` и API на порту из `PORT` (по умолчанию 3001). Если хостинг требует прослушивания внешнего интерфейса, установите `HOST=0.0.0.0` в его серверном окружении. При публикации на Vercel файлы в `api/` работают как серверные функции; в настройках проекта задайте `GEMINI_API_KEY` для Production и сделайте новую публикацию. Не добавляйте ключ в переменные `VITE_*` и не коммитьте `.env`.

Ключ создаётся в [Google AI Studio](https://ai.google.dev/gemini-api/docs/api-key). После заполнения `.env` перезапустите сервер. `GEMINI_MODEL` можно изменить; по умолчанию используется `gemini-3.8-flash`.

## Почему именно такой MVP

В приложенном изображении сформулированы **вопросы исследования**, а не требования к интерфейсу. Они охватывают трудности самостоятельной подготовки, непонятные темы, поиск помощи, барьеры обращения к другим людям и недостающие инструменты. Из этих вопросов нельзя достоверно вывести результаты пользовательских интервью. Мы поэтому не утверждаем, что все студенты испытывают одинаковые проблемы.

Из доступных исследований следует более узкая опора для первой версии:

- Практика воспроизведения ответа и распределение повторений во времени относятся к наиболее полезным методам самостоятельной учёбы ([обзор Dunlosky et al., 2013](https://www.psychologicalscience.org/publications/journals/pspi/learning-techniques.html); [обзор в Nature Reviews Psychology, 2022](https://www.nature.com/articles/s44159-022-00089-1)). Поэтому главный сценарий — **сначала вспомнить, затем открыть ответ**, а сложные карточки возвращаются раньше.
- Для подготовки важно понимать, что уже пройдено и что предстоит. Исследования связывают саморегуляцию и управление временем с откладыванием учёбы ([исследование 450 студентов, 2020](https://www.mdpi.com/2076-328X/10/12/184)). Поэтому на главной видны карточки к повторению, сегодняшняя активность и ближайший экзамен.
- Студенты могут избегать обращения за помощью из-за неловкости, страха оценки и организационных барьеров ([смешанное исследование, 2026](https://www.frontiersin.org/journals/education/articles/10.3389/feduc.2026.1915972/full)). Это причина **проверить** идею помощи в интервью, но не строить в MVP непроверенную социальную сеть или чат без пользователей и модерации.

## Что работает

- Создание, изменение, поиск и удаление предметов; дата экзамена.
- Создание, изменение и удаление карточек «вопрос → ответ».
- Загрузка до 5 файлов лекции: PDF, DOCX, PPTX, TXT, MD, PNG, JPG и WEBP (до 4 МБ вместе из-за [ограничения Vercel](https://vercel.com/docs/functions/limitations)). PDF и изображения передаются в [Google Gemini API](https://ai.google.dev/gemini-api/docs/generate-content/file-input-methods) для визуального анализа; из DOCX, PPTX, TXT и MD сервер извлекает текст. Gemini возвращает карточки в [структурированном формате](https://ai.google.dev/gemini-api/docs/generate-content/structured-output). Можно запросить 6, 10 или 16 карточек. Перед сохранением можно исправить вопросы и ответы, убрать лишние карточки и выбрать предмет.
- Повторение карточек, которым пришло время, либо всех карточек конкретного предмета.
- Три оценки ответа: «не вспомнил» — через 10 минут, «было трудно» — короткий интервал, «знаю ответ» — более длинный интервал. Это простая эвристика для MVP, не научно оптимизированный алгоритм.
- Сводка после сессии и счётчик ответов за сегодня.
- Адаптивный интерфейс; несколько **демонстрационных** предметов и карточек при первом открытии.

Данные карточек сохраняются в `localStorage` текущего браузера. Файлы лекций не сохраняются на сервере приложения: они принимаются в память запроса и отправляются в Google Gemini для анализа; для DOCX/PPTX передаётся извлечённый текст. **Не загружайте материалы, которые нельзя передавать стороннему API.** Созданные ИИ карточки необходимо проверить: модель может ошибаться и пропускать детали. Без `GEMINI_API_KEY` ручная работа с карточками доступна, а генерация показывает сообщение о настройке.

`localStorage` **не синхронизирует данные между устройствами**; очистка данных браузера их удалит. До публичного запуска понадобятся аккаунты, серверное хранение, резервные копии, ограничения количества запросов на пользователя и политика обработки данных. Без них приложение лучше использовать как локальный прототип или закрытое демо.

## Что проверить с реальными студентами дальше

Провести 5–8 коротких интервью по вопросам из изображения: как начинают подготовку, где теряют время, что делают при непонятной теме, почему выбирают конкретный источник помощи. Затем дать студентам создать собственный предмет и пройти несколько сессий. Измерить: дошли ли до первой карточки, вернулись ли к повторению через 2–3 дня, помогают ли даты экзаменов планировать учёбу. Функции обмена карточками или поиска помощника добавлять только после подтверждения соответствующей проблемы.
